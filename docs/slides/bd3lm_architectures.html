Two long-context DNA backbones

Dual-stream Transformer  ·  Leakage-safe bidirectional SSM

Both are drop-in backbones under the same BD3-LM block-diffusion objective, at single-nucleotide resolution on the Carbon corpus.

The shared substrate: BD3-LM block diffusion

Split the sequence into \(N = L/B\) blocks. Each block gets its own noise level \(t_b\); a block is denoised conditioned on all clean earlier blocks. Autoregressive across blocks, diffusion within one.

clean \(x_0\) noisy \(x_t\) (active) masked out of view

Objective and parameterization

Forward process

Absorbing-state masking. With log-linear schedule the move chance is exactly \(t\):

$$q(x_t^i \mid x_0^i) = (1-t)\,\delta_{x_0^i} + t\,\delta_{\mathbf{M}}$$

Each block draws its own \(t_b \sim \mathcal U[\epsilon, 1]\), antithetically stratified over batch × blocks.

SUBS parameterization

Two constraints are baked into the logits, not learned:

$$p_\theta^i(\mathbf{M}) = 0, \qquad x_t^i \neq \mathbf{M} \;\Rightarrow\; p_\theta^i = \delta_{x_t^i}$$

Zero mask probability + carry-over unmasking. Unmasked positions contribute \(\log p = 0\), so only masked tokens carry loss.

Block-diffusion NELBO

$$\mathcal{L} \;=\; \sum_{b=1}^{N}\; \mathbb{E}_{t_b}\!\left[\frac{1}{t_b} \sum_{i \in \mathcal{B}_b} -\log p_\theta^{\,i}\!\left(x_0^i \,\middle|\, x_{t_b}^{\mathcal{B}_b},\, x_0^{<b}\right)\right]$$

The \(1/t_b\) weight is loss_scale in noise_schedule.py; the inner conditioning set is exactly what each backbone must realize without leaking \(x_0^{\mathcal{B}_b}\) or anything to its right.

Every architecture that follows changes only how \(x_0^{<b}\) reaches the denoiser. The loss, the tokenizer, the sampler contract and the evaluation are identical, which is what makes the backbones comparable.

Reference point: the Transformer BD3-LM

One forward pass over a doubled sequence \([x_t; x_0]\) of length \(2L\). A single block mask lets every block be supervised at once: query rows in the \(x_t\) half see their own block bidirectionally, plus the \(x_0\) half strictly before their block.

Cost. Attention is \(O((2L)^2)\). At \(L=8192\) that is a 16k-token attention per layer — affordable with a block-sparse FlexAttention kernel, but it grows quadratically and the KV cache at sampling grows linearly with everything committed.

Variant 2 — dual stream: cheap global context

Keep the fine stream at nucleotide resolution but make its self-attention local (a ±8-block band). Recover long range from a second, much cheaper stream that reads \(x_0\) at \(L/k\) resolution through non-overlapping \(k\)-mers.

Dual stream — why it is leak-free

Two masks do the work

Fine self-attention: the standard BD3-LM mask ANDed with a locality band

$$\text{block}(q) - \text{block}(kv) \le W,\quad W = 8$$

Fine → coarse cross-attention: strictly block-causal. Fine block \(i\) may read coarse token \(j\) only if that \(k\)-mer window lies entirely inside completed context:

$$j \le \left\lfloor \frac{v_i}{k} \right\rfloor - 1, \qquad v_i = \text{visible nucleotides}$$

The subtle part

The position-level cross-attention mask is safe only because the coarse self-attention is causal.

With a bidirectional coarse encoder, a coarse token in the visible past would already have absorbed the clean current and future target through its own self-attention — the mask would look correct and the model would still leak.

Causality also makes \(c_j\) suffix-invariant, so the coarse memory a fine block reads at sampling time is bit-identical to training.

Alignment: keep block_size divisible by k_coarse. Otherwise coverage is slightly short at block boundaries (no leak) and the sampler asserts.

Dual stream — layer equations

Per fine layer, with adaLN modulation \((\gamma,\beta,g)\) produced from the diffusion timestep:

$$\begin{aligned} h &\leftarrow h + g_{\text{self}} \cdot W_o\,\mathrm{Attn}_{\text{local}}\!\big(\mathrm{LN}(h)\odot(1+\gamma_1)+\beta_1\big) \\[2pt] h &\leftarrow h + g_{\text{cross}} \cdot \mathrm{XAttn}\big(h,\; c\big) \\[2pt] h &\leftarrow h + g_{\text{mlp}} \cdot \mathrm{MLP}\!\big(\mathrm{LN}(h)\odot(1+\gamma_2)+\beta_2\big) \end{aligned}$$

Seven adaLN modulators per layer; all gates are zero-init.

Implementation trap recorded in the code. The cross-attention residual is \(g_{\text{cross}} \cdot W_o(\cdot)\). Zero-initializing both the gate and \(W_o\) makes the product a dead zero: the gradient w.r.t. the gate is proportional to \(W_o\) and vice versa, so neither ever leaves zero and the route is permanently disabled. Standard adaLN-zero zeroes only the gate.

In-repo observation: even with that fixed, an aligned-pointer probe run measured \(g_{\text{cross}} \approx 0.044\) — the coarse route stayed largely unrecruited on real DNA, so long-range benefit could not express itself in the loss. That is a finding about the data and the incentive, not a proof the wiring is wrong.

Variant 3 — bidirectional SSM: the target computation

Replace attention with a Mamba-2 selective scan whose boundary state can be handed across segments. Context arrives as a fixed-size recurrent state, not as keys and values.

$$\begin{aligned} s^{\text{left}}_{l} &= \mathrm{scan}\big(x_0^{<b}\big), \qquad s^{\text{right}}_{l} = \mathrm{scan}\big(\mathrm{rev}(x_0^{>b})\big) \\ a^{\text{fwd}} &= \mathrm{scan}\big(x_t^{\mathcal B_b},\, s^{\text{left}}_l\big), \qquad a^{\text{rev}} = \mathrm{rev}\,\mathrm{scan}\big(\mathrm{rev}(x_t^{\mathcal B_b}),\, s^{\text{right}}_l\big) \\ h &\leftarrow h + a^{\text{fwd}} + a^{\text{rev}} \end{aligned}$$

Direct sum, no zero-init route gate — deliberately, so neither direction can be silently switched off the way the dual stream's cross route was.

What lives in a boundary state

The Mamba-2 diagonal selective recurrence, continued from an immutable input state:

$$\begin{aligned} S_i &= S_{i-1}\odot e^{\Delta_i A} + \Delta_i\, B_i x_i^{\top} \\ y_i &= \langle S_i, C_i\rangle + D \odot x_i \end{aligned}$$

A segment state is the pair

$$\texttt{Mamba2State} = \big(\underbrace{\text{conv}}_{d_{\text{conv}} \text{ raw inputs}},\; \underbrace{S}_{H \times P \times \mathcal{N}}\big)$$

Why this is the whole game

Exactness: splitting a scan at any boundary and resuming from the stored state reproduces the one-shot result — verified fused-vs-reference on an H200 (max abs diff 0.0078 in BF16, convolution states bit-exact).

Immutability: denoising the active block never mutates the clean caches, so the same cache serves every diffusion step of that block.

Consequence for sampling: committing a block costs one scan over that block and zero growth in cache size. A Transformer's KV cache grows with every committed token.

Geometry: d=768, 12 layers, state 64, conv width 4, expand 2, head dim 64, chunk 128, block 256 → 100.69M trainable parameters.

The training-objective problem

A Transformer supervises all \(N\) blocks in one pass because the \([x_t;x_0]\) mask packs them together. A recurrent model cannot: each block needs a different boundary state.

v1 — one block per step

$$\hat{\mathcal L}_{\text{one}} = N \cdot \ell_{b},\qquad b \sim \mathcal U\{1..N\}$$

Unbiased for the loss value: \(\mathbb E_b[\hat{\mathcal L}_{\text{one}}] = \mathcal L\).

But gradient reaches only \(1/N\) of the tokens per step. At \(L=8192,\,B=256\) that is \(N=32\) — a 32:1 learning-signal handicap against the Transformer.

A perplexity comparison run this way measures the estimator, not the backbone.

v2 — every block per step

$$\mathcal L_{\text{all}} = \sum_{b=1}^{N} \ell_b \quad\text{(exact)}$$

One clean scan yields the state entering every block; fold blocks into the batch dimension and denoise them in a single call.

All-block supervision by cache folding

Tested: boundary states equal per-block prefills in both directions; folded logits equal block-by-block logits; the two estimators agree on the sampled block; and a per-position sweep confirms block \(i\)'s de-novo logits move only for clean tokens strictly before it.

C-a mode: infilling with a fixed right flank

The same machinery, with the reverse cache built from an observed right flank instead of the empty state. The right cache is prepared once and never mutated as blocks are committed left-to-right.

De-novo perplexity and generation never use a right cache — it would be an oracle. C-a is a separate, conditional task.

The SSM's argument is not that it is a better density model. It is that committing a block costs \(O(1)\) memory, which is what makes chromosome-scale generation and infilling tractable at all.

Where this goes next

Performance

Chunked state passing: compute each block's local scan in one folded call, carry boundary states with a cheap elementwise recurrence, apply the standard output correction. ~24 launches per step instead of ~384 — the same restructuring Mamba-2's chunk scan does internally, one level up.

Science

The likelihood comparison is a floor, not the case. What only the SSM can do:

  • commit at \(O(1)\) memory over chromosome-scale generation
  • C-a infilling against a fixed observed right flank
  • exact resumption from a stored state
