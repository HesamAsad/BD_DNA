Objective and parameterization

Forward process

Absorbing-state masking; under the log-linear schedule the move chance is exactly \(t\):

$$q(x_t^i \mid x_0^i) = (1-t)\,\delta_{x_0^i} + t\,\delta_{\mathbf{M}}$$

Each block draws \(t_b \sim \mathcal U[\epsilon,1]\), antithetically stratified over batch × blocks.

SUBS parameterization

$$p_\theta^i(\mathbf{M}) = 0, \qquad x_t^i \neq \mathbf{M} \Rightarrow p_\theta^i = \delta_{x_t^i}$$

Zero mask probability + carry-over unmasking, so only masked positions carry loss.

Block-diffusion NELBO

$$\mathcal{L} = \sum_{b=1}^{N} \mathbb{E}_{t_b}\!\left[\frac{1}{t_b}\,\ell_b\right]$$ $$\ell_b = \sum_{i \in \mathcal{B}_b} -\log p_\theta^{\,i}\!\left(x_0^i \mid x_{t_b}^{\mathcal{B}_b},\, x_0^{<b}\right)$$

\(1/t_b\) is loss_scale; the conditioning set is what each backbone must realize without leaking.

In the matched de-novo comparison, each architecture changes only how \(x_0^{<b}\) reaches the denoiser. Loss, tokenizer, data and evaluation are held fixed; their sampling implementations differ, and C-a is a separate conditional task.

Dual stream — why it is leak-free

Two masks do the work

Fine self-attention: the BD3-LM mask ANDed with a one-sided locality band,

$$\mathrm{blk}(q) - \mathrm{blk}(kv) \le W, \quad W = 8$$

All base-mask rules already satisfy \(\mathrm{blk}(q)\ge\mathrm{blk}(kv)\); only the query's own active block is bidirectional.

Fine \(\rightarrow\) coarse: strictly block-causal. Fine block \(i\) reads coarse token \(j\) only if that \(k\)-mer window lies wholly inside completed context,

$$j \le \left\lfloor v_i / k \right\rfloor - 1$$

\(v_i\) = nucleotides visible to block \(i\).

The subtle part

The cross-attention mask is safe only because the coarse self-attention is causal.

With a bidirectional coarse encoder, a coarse token in the visible past would already have absorbed the clean current and future target through its own self-attention. The mask would look correct and the model would still leak.

Causality also makes \(c_j\) suffix-invariant, so the memory read at sampling time is identical to training.

Keep block_size divisible by k_coarse; otherwise coverage falls slightly short at block boundaries (no leak) and the sampler asserts.

Dual stream — layer equations

Per fine layer, with adaLN modulation \((\gamma,\beta,g)\) from a conditioning embedding:

$$\begin{aligned} h &\leftarrow h + g_{\text{self}}\, W_o\,\mathrm{Attn}_{\text{loc}}\!\big(\mathrm{LN}(h)(1+\gamma_1)+\beta_1\big) \\ h &\leftarrow h + g_{\text{cross}}\, \mathrm{XAttn}(h, c) \\ h &\leftarrow h + g_{\text{mlp}}\, \mathrm{MLP}\!\big(\mathrm{LN}(h)(1+\gamma_2)+\beta_2\big) \end{aligned}$$

Seven adaLN modulators per layer; all gates zero-init. In the production BD3-LM configs, time_conditioning=false, so the supplied \(\sigma\) is zeroed and these modulators are constant with respect to diffusion time.

Trap recorded in the code. The cross residual is \(g_{\text{cross}}\cdot W_o(\cdot)\). Zero-initializing both factors makes the product a dead zero — \(\partial/\partial g \propto W_o\) and \(\partial/\partial W_o \propto g\) — so neither leaves zero and the route is permanently off. adaLN-zero zeroes only the gate.

In-repo observation: even with that fixed, an aligned-pointer probe measured \(g_{\text{cross}} \approx 0.044\) — the coarse route stayed largely unrecruited on real DNA. A finding about data and incentive, not proof the wiring is wrong.

$$\begin{aligned} a^{\text{fwd}} &= \mathrm{scan}\big(x_t^{\mathcal B_b},\; s^{\text{left}}_l\big), \qquad a^{\text{rev}} = \mathrm{rev}\,\mathrm{scan}\big(\mathrm{rev}(x_t^{\mathcal B_b}),\; s^{\text{right}}_l\big) \\ h &\leftarrow h + a^{\text{fwd}} + a^{\text{rev}} \end{aligned}$$

Direct sum, no zero-init route gate — deliberately, so neither direction can be silently switched off the way the dual stream's cross route was.

What lives in a boundary state

Mamba-2's diagonal selective recurrence, continued from an immutable input state:

$$\begin{aligned} S_i &= S_{i-1}\odot e^{\Delta_i A} + \Delta_i B_i x_i^{\top} \\ y_i &= \langle S_i, C_i \rangle + D \odot x_i \end{aligned}$$

A segment state is the pair

$$\big(\underbrace{\text{conv}}_{d_{\text{conv}}\ \text{raw inputs}},\; \underbrace{S}_{H \times P \times \mathcal{N}}\big)$$

Why this is the whole game

Continuation. Splitting a scan at any boundary and resuming from the stored state matches the one-shot result to BF16 kernel tolerance — verified fused-vs-reference on an H200 (max abs diff \(0.0078\); convolution states bit-exact).

Immutability. Denoising never mutates the clean caches, so one cache serves every diffusion step of that block.

Committing a block costs one scan over that block and zero growth in recurrent-cache size. The returned token buffer still grows.

\(d=768\), 12 layers, state 64, conv width 4, expand 2, head dim 64, chunk 128, block 256 → 100.69M parameters; \(\approx\)2.40 MiB per direction in BF16 at batch 1.

The training-objective problem

A Transformer supervises all \(N\) blocks in one pass because the mask packs them together. A recurrent model cannot natively reuse one boundary: each block needs a different state.

v1 — one block per step

$$\hat{\mathcal L}_{\text{one}} = N \cdot \ell_b, \quad b \sim \mathcal U\{1..N\}$$

Unbiased for the loss value, \(\mathbb E_b[\hat{\mathcal L}_{\text{one}}] = \mathcal L\).

But gradient reaches only \(1/N\) of the tokens per step. At \(L=8192, B=256\) that is \(N=32\) — 32× less token supervision and a much noisier estimate.

v2 — every block per step

$$\mathcal L_{\text{all}} = \sum_{b=1}^{N} \ell_b \quad \text{(exact)}$$

One clean scan yields the state entering every block; fold blocks into the batch dimension and denoise them together.

Two MC-8 seeds; per-variant seed agreement is only \(\approx0.48\), so this is preliminary. All targets are \(\le216\) nt and fit inside one 256-nt block: this benchmark does not exercise the prefix or C-a caches. dnaHNet is a reference bar, not a matched control: 144B training nt and exact AR likelihood versus our 4.19B nt and diffusion NELBO.

Full-forward scaling, one H200

BiSSM stays near 18k nt/s through 512K, but remains 2.0× slower than the Transformer at 256K. The Transformer stops at 512K on a Triton 32-bit indexing limit, not GPU OOM.

Both full-likelihood paths use \(O(L)\) memory: BiSSM retains every block boundary to score all blocks (38.70 GiB at 512K). Constant cache memory applies to incremental denoise_block + commit, which still needs a dedicated benchmark.

Next decisive experiment

Does the model use the prefix state?

Run a fixed-corruption, depth-resolved intervention on 512 validation sequences:

  • full prefix versus no prefix
  • same-depth shuffled prefix state
  • only the last 256 nt or 1024 nt

Report \(\Delta\)NLL by block depth. This directly tests the recurrent route that MaveDB and aggregate perplexity do not isolate.

Then, only if the route is live

Benchmark incremental denoise_block + commit for throughput and peak cache memory; next run the dnaHNet-aligned DEG subset. Train a suffix-conditioned checkpoint before claiming C-a quality. Chunked boundary construction is the main training-speed optimization, but it should not replace the causal-use test.
